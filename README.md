# Simone Quattromini - Developer Portfolio

> A personal developer portfolio with a unique terminal/cyberpunk aesthetic, designed to showcase my projects.

## 🖥️ Overview & Style

This portfolio is designed with an immersive **Terminal / Matrix** theme. It aims to provide a unique developer experience through:
- **Terminal UI Elements**: Features typewriter text effects, system status logs, and developer-centric terminology (e.g., `Establishing Secure Connection...`, `./active_deployments --list`).
- **Visual Effects**: Custom `scanline` overlays, `matrix-bg` matrix-style backgrounds, and neon-glow accents.
- **Interactive Animations**: Smooth scroll effects, custom component reveals, and interactive buttons using Framer Motion.

## Technologies Used

This project is built with a modern web development stack:

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Features

- **Project Showcase**: A dedicated section to display featured projects with quick repository access.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop environments.
- **Typewriter Effects & Scanlines**: Custom-built components to enhance the terminal look and feel.

## Getting Started

First, clone the repository and install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
